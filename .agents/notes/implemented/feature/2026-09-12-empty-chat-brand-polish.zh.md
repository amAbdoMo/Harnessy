# Agent Note: 空聊天品牌细节优化

Status: implemented

[English](2026-09-12-empty-chat-brand-polish.md) | 中文

## Problem

空聊天标题仍显示 **Preview** 标记，而 Harnessy 现在已经是正式产品身份。它的 34px 品牌位还会选择用于大尺寸场景的透明标记，然后在会裁剪的渐变容器中放大，导致图形看起来被截断，也与侧边栏不一致。

## Decision

空聊天标题只保留 Harnessy 标记与 **Into the Unknown** 文字。移除 Preview 标签、对应的本地化字段和展示样式。

Harnessy 在不超过 40px 的紧凑界面中使用完整的应用图标，同时覆盖 24px 侧边栏位和 34px 空聊天位。更大的品牌区域继续使用透明标记素材。

## Alternatives considered

- **保留标签但改名** — 放弃，因为永久的产品界面不应带有临时发布状态标签。
- **继续使用透明标记并调整缩放** — 放弃，因为小尺寸位更适合已经调整好的应用图标，否则会在 CSS 中重复图标合成逻辑。
- **所有尺寸都使用应用图标** — 放弃，因为大型展示区域仍更适合透明标记。

## Consequences

首屏现在只展示一个更简洁、稳定的产品身份。空聊天图标与清晰的侧边栏图标保持一致，不改变大尺寸品牌场景的行为。组件测试会验证标签已移除，以及侧边栏、空聊天和大尺寸场景所选用的素材。
