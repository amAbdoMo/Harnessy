# 原生伴侣启用

[English](guide.md) | 中文

## 变更

两个伴侣环境变量均未配置时，Desktop 加载应用持有的中继部署配置。用户在原生手机设置中明确启用连接前，不创建电脑身份或联系中继。已提交且绑定来源的许可会在后续普通启动时恢复连接。现有手机授权、身份密钥与指纹批准机制保持不变。

通过 `DSH_DESKTOP_COMPANION_HTTPS_ORIGIN` 与 `DSH_DESKTOP_COMPANION_BUDGETS` 提供的完整运维覆盖配置仍须同时生效。部分、空白或无效覆盖配置会失败，不会回退到已打包的部署配置。移除两个覆盖值现在会选择产品部署配置，不再禁用部署。明确打包为 `{}` 的部署仍保持禁用。

## 迁移

1. 通过普通应用更新流程安装已验证的 Desktop 更新。源码修改不会更新正在运行的应用；不得在活动实例下重建浏览器或 Desktop 产物。
2. 打开 **设置 → 通用 → Android 手机伴侣 → 手机设置**，并明确选择 **启用**。请保持电脑唤醒并运行 Harnessy。中继连接后，创建邀请，并仅批准完整且匹配的手机指纹。启用连接不会批准手机。
3. 已配对手机保留其密钥与授权。请勿删除凭据或重新生成电脑身份。本地许可单独存储为 `companion-host/desktop-consent`；损坏、来源改变与许可撤回均会禁止访问。
4. 确认普通 Desktop 重启后，手机无需试验版辅助启动器即可重新连接。已配置部署不代表中继在线、设备已执行或加密配对成功；这些结果必须分别验证。需要禁用部署的运维方必须打包明确禁用的部署配置并退役运行中的 Host，而不能仅移除覆盖值。
