# 所选额度重置的刷新范围

[English](guide.md) | 中文

## 变更

`accounts.consumeResetCredit()` 仅刷新并提交所选重置额度所属成员身份的用量。返回的 `AccountsState` 仍包含所有已保存账户，但其他成员身份保留之前的用量快照。重置兑换不会触发自动账户选择。依赖兑换后的全账户刷新或附带故障转移的 Remote 调用方必须显式请求该操作。

## 迁移

1. 使用 `accounts.consumeResetCredit()` 兑换所选重置额度，并从返回状态读取该成员身份已刷新的用量。重试尚未确认的操作时，保留相同的账户与重置额度专属幂等键。
2. 如果调用方需要所有 Codex 成员身份的最新用量或已启用的自动账户选择，请在兑换后显式调用 `accounts.refreshUsage(signal)`。
3. 确认兑换操作保留当前身份且不改变其他成员身份的用量时间戳；显式全量刷新会更新这些成员身份，并保留配置的自动选择行为。
