# 保存的网站访问权限

[English](guide.md) | 中文

## 变更

保存的网站配置支持“自动”“每次询问”和“禁用”，独立于文件系统权限。自动请求会打开相应账号的标签页，等待原生准入，无需逐次操作审批。暂停保留已保存的登录信息；继续会选择下一个等待中的请求。应用最小化时自动任务仍可运行。页面丢失、账号变更、取消及 Host 替换仍会撤销请求。

网站配置元数据升级到版本 2。版本 1 配置以“每次询问”加载，保留身份、地址、MCP 绑定和浏览器存储。下一次配置修改会写入版本 2；旧版本应用无法读取该版本。可选的已保存密码存储在独立的本地系统加密保险库中，不进入模型消息或配置元数据。自动登录支持同源的常规登录表单；多因素认证及不支持的流程需要用户操作。

## 迁移

1. 保留当前安装的数据目录。不要在正式安装与暂存应用之间复制浏览器配置或凭据。
2. 打开保存的网站，选择一次“自动”以允许该账号的无人值守操作。现有配置在手动更改前保持“每次询问”；“禁用”阻止 Agent 工作但保留配置。
3. 可选择“保存登录信息”。自行完成多因素认证或不支持的登录流程，再按“继续”。退出登录会清除浏览器认证并恢复“每次询问”；移除已保存登录会删除加密凭据，删除配置会在清理成功后移除配置及其加密凭据。
4. 确认受信任网站请求无需审批提示即可执行，且暂停后不再执行 Agent 操作。网站 Cookie 仍会按网站自身策略过期。
