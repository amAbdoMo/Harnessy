# 从 Android 打开已有聊天

[English](<guide.md>) | 中文

## 变更

Android 可在电脑保持运行时显式打开符合条件的已有冷态普通聊天，无须打开桌面标签页。仅列出会话或查看历史绝不会激活 Agent。冷态激活使用电脑的常规 Agent 配置与恢复流程，并只刷新目标 Session；初始化可能迁移或修复历史、运行 SessionStart 插件，即使失败也可能留下这些影响。已运行的 Agent 会被复用。打开聊天不会发送文本或新任务、改变全局模型默认值、激活已归档或子智能体聊天，也不会重新启用目标。

会话激活使用电脑端独立的 `sessionActivationV1` 授权，默认拒绝。配对、聊天管理、模型选择及工具详情授权均不会启用它。手机重命名和提交文本要求聊天已打开，绝不会因此激活冷态 Agent。打开一个聊天不会停止另一个 Agent；更改模型仍要求目标聊天空闲。草稿仅保存在 RAM 中，并按原电脑与聊天隔离；未解决的送达围栏也按电脑与聊天隔离。

Android 读取有效的 v1/v2 送达围栏文档时不会重写。下一次合法写入会生成 v3，围栏按电脑与聊天保存；旧 Android 构建无法安全读取 v3。不要通过清除送达记录或降级应用来消除结果未知警告。电脑身份记录兼容性见[模型与工具授权指南](<../companion-model-and-tool-consent/guide.zh.md>)。

## 迁移

1. 先通过常规应用内更新流程更新电脑，再安装匹配的 Android 构建。保持电脑唤醒并运行 Harnessy；无须打开桌面聊天标签页。
2. 在桌面**设置 → 常规 → Android 手机伴侣 → 手机设置 → 已配对手机**中比较完整手机指纹，并显式选择**启用打开聊天**。模型选择及工具详情仍须分别决定。
3. 在 Android 上选择已关闭会话以查看历史，再选择**打开聊天**。电脑确认激活并返回最新状态后，输入区域变为可用。仅在该聊天空闲且已单独授予模型权限时选择模型。
4. 在 Android 上打开另一个符合条件的会话，并在二者之间切换。打开或选择一个聊天不得停止另一个 Agent、移动其草稿或更改其模型。此操作不能激活已归档或子智能体会话。
5. 若打开或其他变更的结果未知，检查该聊天当前的电脑状态，并显式处理其送达警告。不要自动重发。确认配对、原有围栏、其他聊天草稿及全局模型默认值保持不变。
