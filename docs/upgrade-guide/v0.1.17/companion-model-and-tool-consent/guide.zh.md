# 手机模型选择与工具详情授权

[English](guide.md) | 中文

## 变更

手机模型请求需要更新后的电脑 Host。旧电脑会拒绝新增的封闭协议操作。配对既不授予模型选择，也不授予工具详情；每项权限均须在电脑原生界面核对手机完整指纹后单独决定。聊天管理授权不包含这两项权限。

电脑读取 v1–v4 伴随身份记录时，不会在启动时重写记录。合法的身份或授权写入会保存为 v5，新增可选的 `sessionActivationV1` 授权标志（缺失即拒绝），并保留密钥、代次和其他权限。旧 Host 无法读取 v5；请勿编辑或降级该记录。

## 迁移

1. 安装启用模型功能的 Android 构建前，先更新电脑伴随支持。保留现有 Harness 主目录与配对；不要重置或复制身份密钥。
2. 打开电脑 Android 伴随设置中的**已配对手机**。比较完整指纹，仅在需要时分别启用**模型选择**和**工具详情**。两项权限默认均拒绝。工具详情会披露历史与实时活动中可能敏感的文件名；禁用传送无法抹去已经接收的文本。
3. 在 Android 上选择一个电脑端已运行且空闲、没有排队任务的普通聊天，然后选择电脑已配置的模型。选择仅影响该聊天的下一次模型请求，并采用所选模型的默认推理强度；全局模型默认值保持不变。获准后丢失确认表示结果未知，并不意味着可以安全重试。
4. 启用工具详情后，查看受支持的文件系统活动。成功结果可显示工作区相对文件标签、读取范围、固定写入／编辑结果及搜索计数。外部路径、文件内容、原始命令、差异和错误诊断均不传送。缺少元数据或调用关联时仅显示固定状态；嵌套 PTC 详情不可用。
5. 写入授权后，继续使用支持 v5 的电脑构建。若要停止某项功能，请在**已配对手机**中禁用对应权限，不要降级身份记录。确认配对和其他权限保持不变。
