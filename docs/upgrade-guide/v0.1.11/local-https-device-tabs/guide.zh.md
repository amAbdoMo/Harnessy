# 本地 HTTPS 设备标签页使用独立存储

[English](guide.md) | 中文

## 变更

访问 `localhost` 或字面回环、私有及链路本地 HTTPS 地址的普通 Desktop Browser 标签页，每页使用全新存储分区。它们不共享工作区 Cookie 或其他设备标签页的登录状态。在存储范围之间切换会替换 guest，丢失其原生历史和页面内存。既有已保存账号分区及普通公共网站的工作区共享保持不变。[Desktop Browser 策略](../../../../apps/desktop/README.zh.md#local-https-devices) 说明了证书的明确确认和不受支持的 POST 切换。

## 迁移

1. 在普通 Browser 标签页中打开本地设备，必要时重新登录。访问期间保持该标签页打开；关闭它会清除临时登录存储。
2. 如果出现未经验证的证书警告，请检查设备地址和证书指纹。除非认识该设备并信任当前网络，否则取消。接受证书仅适用于该独立标签页。
3. 确认第二个标签页不会继承第一个标签页的设备登录或证书接受。不需要修改设置键、安装证书或迁移持久化 Session 数据。
